1. Install Node.js and MySQL, start MySQL.
2. Open .env and put your MySQL password in DB_PASSWORD.
3. In this folder run:   npm install
4. Then run:            npm start
5. Open http://localhost:3000

Student: sign up with an email containing "viva" (e.g. rahul@viva.edu)
Admin:   click "Admin Login" -> email/password from .env (default admin@viva.edu / Admin@123)
